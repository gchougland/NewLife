# New Life

Choose where you start when you first join a world.

The first player to join sees a menu. Pick a start, and you are moved to a safe spot that matches your choice. Dying does not open the menu again.

## Start options

- Anywhere
- Above ground
- Underground
- Choose a zone (Emerald Wilds, Howling Sands, Whisperfrost Frontiers, or Devastated Lands)
- Start in a dungeon
- Start on an island

Dungeon starts pick from places like cursed crypts, outlander camps, trork fortresses, ancient ruins, wind temples, scarak nests, goblin lairs, and mineshafts.

## Extra settings

- **Random for each player.** Later players get their own menu when they first join. If this is off, everyone uses the first player's start.
- **New place after death.** After you die, you are sent to a new spot of the same type instead of the same place.
- **Ignore beds.** You respawn at your chosen start even if you have a bed.

## Command

Use `/newlife` to open the menu again at any time.
